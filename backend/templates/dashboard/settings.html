Security & SSRF Engine

PulseAPI enforces kernel-grade outbound HTTP destination filtering:

  • Schemes: HTTP & HTTPS only
  • Credential Blocking: Embedded username/password in URLs prohibited
  • IP Blocking: Loopback (127.0.0.0/8), RFC1918 Private (10/8, 172.16/12, 192.168/16), Link-Local (169.254/16), Multicast, and Cloud Metadata (169.254.169.254) strictly denied
  • Redirect Guard: Bounded 3xx redirects re-resolved and re-validated before following
  • Response Ceiling: 2MB payload ceiling to eliminate memory exhaustion attacks
